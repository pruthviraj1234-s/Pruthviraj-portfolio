## 🌐 How to Host Online for FREE (Within 2 Minutes)

- **Option 1: GitHub Pages (Recommended)**
  1. Create a GitHub repository named `portfolio`.
  2. Upload these files (`index.html`, `style.css`, `script.js`).
  3. Go to **Settings** -> **Pages** -> Set Branch to **main** -> Click **Save**.
  4. Your website will be live at `https://yourusername.github.io/portfolio`!

- **Option 2: Netlify Drop**
  1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
  2. Drag and drop the `project` folder.
  3. Your live link is generated instantly!
